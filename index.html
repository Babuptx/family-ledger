📖 Operating Manual

Welcome to the Ledger Dashboard. This tool strictly calculates proportional splits and overflow metrics.

1. Initialization (Initial Merge)

Establish your baseline by defining the starting Date and the base values for both the CkPr and CpRs accounts. This action locks in the structural split percentages.

2. Recording Updates

Use Add Market Update to log a new total valuation. The system will automatically calculate the gain/loss delta and distribute it proportionally based on the active split ratio.

3. Managing Overflow

If a Market Update pushes the Total Balance above the maximum designated limit, the system will prompt an Overflow Withdrawal. Capital must be withdrawn from the CpRs account to level the balance. Executing a withdrawal automatically recalibrates all future split percentages.

4. Stateless Data Sync

This dashboard operates in Stateless Mode. Data is never cached or stored in the cloud. You must use Save JSON As... to download your ledger locally. Upon your next visit, use Load JSON (Drive) to securely restore your session.
