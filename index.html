Family Ledger — SOP and help

  1. Start or load. For a new ledger, enter the baseline date and each starting bucket balance. To continue an existing ledger, use Load JSON backup. Existing legacy array backups are upgraded safely on import.
  2. Use USD for entries. Record a new total whenever you value the combined accounts. The app allocates the change to buckets using the current split and whole-cent rounding.
  3. Add fresh money. Use Add new funds to put money such as a new $5,000 directly into any bucket. The total and split percentages update from the new composition.
  4. Move money with a transfer. Pick the source, destination, date, and amount. Transfers cannot exceed the source balance.
  5. Add accounts when needed. Use “Add another bucket” for a name such as SANp. It starts at zero; use a transfer or new-funds entry to fund it.
  6. Review the limit prompt. Totals above $500,000 open a reminder. Record a validated withdrawal from any bucket or keep the balance unchanged.
  7. Save routinely. Save a timestamped JSON backup after changes, preferably in your own protected cloud folder. JSON is the canonical backup; Excel is a presentation report.
  8. Start another ledger safely. The “Start another new ledger” button opens a separate blank ledger window. Your current window and in-memory ledger stay unchanged.
  9. Live local time. The panda title updates every second using this browser’s local time zone. It does not perform an IP-location lookup.
  10. Privacy. The app does not upload ledger data. It fetches the USD/INR rate automatically on page load and lets you refresh it; Excel export loads only when requested. Those third-party services receive ordinary connection metadata, never intentionally ledger values.
  11. Safety. Load only family backups you trust. JSON is editable and this tool is a family organizer, not audited accounting software.
